# 网络电台曲库

把音乐文件放进这个目录（可以建子目录），页面右上角的电台按钮就会出现。

- **支持格式**：mp3 / m4a / aac / ogg / opus / flac / wav
- **时长**：mp3 / wav / flac / ogg 都能精确读出，排期按真实时长走；其它格式按码率估算。
- **曲名与艺术家**优先读 MP3 的 ID3 标签（`TIT2` / `TPE1`）；没有标签时才退回
  文件名（去掉扩展名，下划线换成空格）。音乐 App 缓存下来的文件常是 `M800000dB5PY0Fmiev.mp3`
  这种哈希名，只按文件名显示等于没有曲名。
- **所有人听到的是同一首歌的同一位置**：顺序按文件名排，服务器定这一轮从哪一刻开始，
  谁在什么时候打开页面，都从中途切进去。播完接下一首，到末尾绕回开头。
  （所以这里没有「上一首/下一首」，只有一个频道。）
- 目录里没有音频文件时，电台入口不会显示——不会留一个点了没反应的按钮。
- 目录内容更新后最多 8 秒生效（列表有缓存），不需要重启；正在播的那首会原位接上。

## 用已有的音乐库

不必把文件搬进来。在 `backend/.env` 里指定路径即可：

```dotenv
RADIO_DIR=D:\Music
```

改完重启后端。这个目录只会被**只读**读取，不会写入、不会移动、不会改名。

> 音乐文件的版权属于各自的作者。这个目录被 `.gitignore` 排除，不会被提交。
